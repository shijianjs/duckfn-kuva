# v0.1.0

发布于 2026-10-10。链接 **kuva 0.5.0**。

[GitHub Release](https://github.com/shijianjs/duckfn-kuva/releases/tag/v0.1.0) ·
[v0.1.0 之前的全部提交](https://github.com/shijianjs/duckfn-kuva/commits/v0.1.0)

这是第一个打过 tag 的版本，没有上一个 tag 可以比较 —— 上面那个链接列的就是它的全部历史。

## 改了什么

**kuva 的全部 64 种图型**，按分布、关系与相关、分类与对比、时间序列、统计与模型评估、层级与网络、3D、
组合与工具分组。每种图型在本站都有可运行的例子和完整的字段表。

**三个函数**（`kuva_render_typst` 与 `kuva_version` 是后来才有的）。

| 函数 | 返回 |
| --- | --- |
| `kuva_render(json)` | 一份 SVG 文档 |
| `kuva_render_terminal(json)` | 终端文本 —— 盲文点阵 + ANSI 色 |
| `kuva_render_file(json)` | 它写出的 SVG 文件路径，可选在浏览器里打开（仅原生构建） |

**多面板 figure。** 顶层 `figure` 对象带 `rows`、`cols`、`panels`，把几张图排成网格，共享坐标轴与可选的
共享图例。

**规格的其余部分。** 主题、具名调色板、标注、坐标轴与图例选项、灰度（无障碍）模式，以及后续版本一直在
扩展的那套 snake_case JSON 布局。

不合法的输入会让查询直接报错并说明问题，而不是返回 `NULL`。
