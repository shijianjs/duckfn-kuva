<dfk-features section-title="为统计图而做">

<dfk-feature icon="lucide:sigma" title="统计语义，而不只是画个形状">
对标 seaborn 与 ggplot2：你只描述这张图要什么，坐标轴、分箱、刻度、排版都交给扩展 —— 正是这一点让一张图成为统计图，而不只是装饰。
</dfk-feature>

<dfk-feature icon="lucide:shapes" title="64 种图型，可组合">
从散点、直方图、箱线图，到小提琴图、桑基图、K 线图、热力图。多个 series 可以叠在同一套坐标轴上，也可以排成多面板 figure，共享图例，并带第二根 y 轴。
</dfk-feature>

<dfk-feature icon="lucide:braces" title="一个函数：JSON 进，SVG 出">
kuva_render 就是普通的 DuckDB 函数：给它一段 JSON 图表规格，它返回一份完整的 SVG 文档，调用处不用 import 任何东西，中间也没有宿主绘图库。
</dfk-feature>

<dfk-feature icon="lucide:monitor-down" title="同一张图，每个平台都一样">
同一份 .duckdb_extension，在 CLI、Python / R 会话、JVM、浏览器（DuckDB-Wasm）里画出它 —— 不需要 matplotlib、不需要 ggplot2，宿主机上什么都不用装。
</dfk-feature>

<dfk-feature icon="lucide:play" title="例子就地能跑">
本站每个例子都在你的浏览器里用 DuckDB-Wasm 真跑 —— 在图型总览或函数页点一下「执行」，就能看到真实画出来的图。
</dfk-feature>

<dfk-feature icon="lucide:package" title="一行装好">
INSTALL duckfn_kuva FROM community; 再 LOAD duckfn_kuva; —— 构建签过名、且与你的 DuckDB 版本和平台匹配，所以不用加 -unsigned。
</dfk-feature>

</dfk-features>

## 装一次，之后就在 SQL 里调用

扩展加的就是一批普通的 SQL 函数，调用处不用 import 任何东西。左边装一次，之后把任意查询的数据交给 kuva_render，右边就还你一张 SVG 图。

<div className={styles.codeGrid}>

```sql title="duckdb"
-- once per installation, then once per session
INSTALL duckfn_kuva FROM community;
LOAD duckfn_kuva;
```

<div className={styles.codeColumn}>

```sql title="duckdb"
SELECT kuva_render('{"series":[{"type":"scatter","data":[[1,2],[3,4],[5,3]]}]}');
-- an SVG document
SELECT kuva_render('{"series":[]}');
-- error: kuva_render: `series` must not be empty: a single-figure chart needs at least one series
```

注释就是每次调用的返回值 —— 第一个是图表渲染出的 SVG，第二个是一段坏规格如何报错。
