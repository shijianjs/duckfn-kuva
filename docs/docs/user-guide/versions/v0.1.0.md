# v0.1.0

Released 2026-10-10. Wraps **kuva 0.5.0**.

[GitHub Release](https://github.com/shijianjs/duckfn-kuva/releases/tag/v0.1.0) ·
[All commits up to v0.1.0](https://github.com/shijianjs/duckfn-kuva/commits/v0.1.0)

This is the first tagged release, so there is no previous tag to compare against — the link above lists
the whole history that went into it.

## What changed

**All 64 plot types of kuva**, grouped as distributions, relationships and correlation, categorical and
comparison, time series, statistical and model evaluation, hierarchical and network, 3D, and composite
and utility. Every type is documented on this site with a runnable example and its full field list.

**Three functions** (`kuva_render_typst` and `kuva_version` arrived later).

| Function | Returns |
| --- | --- |
| `kuva_render(json)` | an SVG document |
| `kuva_render_terminal(json)` | terminal text — braille dots and ANSI colour |
| `kuva_render_file(json)` | the path of the SVG file it wrote, optionally opened in a browser (native builds only) |

**Multi-panel figures.** A top-level `figure` object with `rows`, `cols` and `panels` lays several charts
out in a grid with shared axes and an optional shared legend.

**The rest of the spec.** Themes, named palettes, annotations, axis and legend options, grayscale
(accessibility) mode, and the snake_case JSON layout that later releases keep extending.

Malformed input fails the query with an actionable message rather than returning `NULL`.
