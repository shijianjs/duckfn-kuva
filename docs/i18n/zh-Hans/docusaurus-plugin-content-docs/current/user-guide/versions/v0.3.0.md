# v0.3.0

发布于 2026-10-19。链接 **kuva 0.6.0**（此前是 0.5.0）。

[GitHub Release](https://github.com/shijianjs/duckfn-kuva/releases/tag/v0.3.0) ·
[自 v0.2.0 以来的提交](https://github.com/shijianjs/duckfn-kuva/compare/v0.2.0...v0.3.0)

## 改了什么

**新的输出后端。** `kuva_render_typst(json)` 把同一段规格渲染成 Typst 源码 —— 一份含 CETZ 矢量图的
`.typ` 文档，交给 `typst compile` 自己编译。它没有选项对象，但和其它函数一样接受可选的数据集参数。

**组合图。** 新增顶层 `composite` 对象（`type: coverage` 或 `brick_pop`），分别画基因组浏览器的覆盖度图
和群体等位基因频率图。它与 `series`、`figure` 互斥，自带画布尺寸，也不读数据集。见
[组合图](../reference/composites.md)。

**scatter。** 标记形状扩到十种（新增 `triangle_down`、`star`、`pentagon`、`hexagon`），`trend` 支持
`loess`（带 `span`，0.05–1），数据点可以带自己的 `labels`，共用一份 `label_style`。标签摆放规则提到
了共用的 series schema 里，所以 `scatter`、`volcano`、`manhattan` 都以同样的方式支持 `repel`。

**histogram。** 新增 `step`、`cumulative`、`bin_method`（`sturges` / `scott` / `freedman_diaconis`，别名
`fd`）、`weights`，以及带堆叠的 `groups`。

**较小的增量。** `survival` 新增 `risk_table`、`median_lines`、`logrank_pvalue`（log-rank 检验替你算好）；
`strip` 新增 `horizontal`；`brick` 新增 CIGAR 条（`cigars`、`dedup`、`run_bracket`、`colors`）、`sort`
（`none` / `cigar` / 自定义行序）与纵向参考线 `marker_lines`；另有 `font.tick_family` 和十五组 LTC 调色板。

**新函数。** `kuva_version()` 返回当前加载的构建编译时链接的 kuva 版本。

## 破坏性变更

- **STRIGAR 语法。** kuva 0.6 不再接受旧的 `|` / `@` 写法。现在是 `<次数><字母>` 首尾相接的串，字母按
  base-26 双射（例如 `10A5B`）。扩展会把 `strigar_issues` / `cigar_issues` 升级成点名到行的错误，而不是
  静默画出一张错的图。

除此之外都是新增：为 0.2.0 写的规格仍然可用，STRIGAR 字符串除外。
